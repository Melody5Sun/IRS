# IT CareerPilot 视频风格指南（视频二用）

> 视频一（推广片，`IT-CareerPilot-Video1.mp4`）已经按这份规范做完。视频二（系统设计 / 技术讲解）沿用同一套视觉，两支片子放在一起看起来就是同一个品牌。
> 所有颜色和字体都直接取自产品前端 `SystemCode/frontend/src/styles/tokens.css`，所以片子和产品界面也是一致的。

---

## 1. 配色

| Token | HEX | 用途 |
|---|---|---|
| `paper` | `#F3F2F0` | 默认背景（米白纸色），绝大多数画面用它 |
| `ink` | `#142435` | 正文、标题；也用作「强调页」的深色背景（开场、总结、片尾） |
| `muted` | `#68717A` | 次要说明、来源、小字 |
| `line` | `#D4D1CD` | 分隔线、卡片边框 |
| `accent` | `#B56E1C` | 铜橙强调色：小标题（kicker）、编号、图标描边、高亮边框 |
| `dark` | `#8A5014` | 浅底上的强调文字（价格、高亮词） |
| `soft` | `#F5E7D1` | 高亮块底色（选中卡片、关键词底） |
| `green` | `#285F3A` | 「Highly Recommended」等正向状态 |
| `red` | `#9B3028` | 错误、风险提示 |
| 深底上的强调 | `#E9C79A` | 深色（ink）背景上的强调文字和按钮 |

**规则**
- 一个画面最多一个强调色（铜橙），不要再引入蓝、紫等新颜色。
- 深色页只用在段落开场、总结句、片尾；讲解内容放在米白底上。
- 实拍素材上叠文字时，加一层 `ink` 半透明遮罩（不透明度 0.45–0.55）。

## 2. 字体与字号（1920×1080 画布）

| 层级 | 字体 | 字号 / 字重 | 示例 |
|---|---|---|---|
| 大标题 | Cormorant Garamond（衬线） | 120–150 px / 400 | "The Challenge" |
| 页面标题 | Cormorant Garamond | 84–96 px / 400 | "Responsible by design" |
| 小标题（kicker） | Inter（无衬线） | 22 px / 500，字间距 0.3em，全大写，铜橙色 | "BUILT ON TRUST" |
| 卡片标题 | Cormorant Garamond | 46–56 px | "Understand" |
| 正文 / 要点 | Inter | 22–28 px / 400 | "Every recommendation shows its evidence" |
| 引语 | Cormorant Garamond Italic | 44 px | “I feel like I'm way behind.” |
| 大数字 | Cormorant Garamond | 180–210 px，等宽数字 | "385" |
| 编号 | Cormorant Garamond，铜橙 | 34–46 px | "01" "02" |

两款字体都是 Google Fonts，免费商用。剪映里没有的话，可以从 fonts.google.com 下载安装。

## 3. 版式

- **安全边距**：左右 120 px；上方 110–150 px。
- **对齐**：文字一律左对齐；只有片尾的品牌页居中。
- **分隔线**：标题下方一条 1.5 px 的 `ink` 细线，从左往右画出（约 1 秒）。
- **卡片**：直角或 4 px 圆角，1.5 px `line` 色边框；高亮卡片换成 `accent` 边框 + `soft` 底，并加一点阴影。
- **结果标签**（演示画面左下角）：米白底、1.5 px 铜橙边框、4 px 圆角。内容是「铜橙编号 + 粗体关键词 + 灰色说明」，例如 `02  Match  Every recommendation comes with evidence`。
- **品牌字标**：`CareerPilot`（Cormorant Garamond）+ 右侧小字 `IT JOB REASONING SYSTEM`（Inter，字间距 0.28em，铜橙）。

## 4. 动效

| 参数 | 值 |
|---|---|
| 性格 | 专业、克制、可信（B2B 预设） |
| 入场 | 淡入 + 上移 24 px，**21 帧（0.7 秒）**，缓动 `cubic-bezier(0, 0, 0.2, 1)`，**不弹跳** |
| 逐条出现 | 同一组元素间隔 1.5–2 秒，和旁白的节奏对齐 |
| 录屏运镜 | 录屏默认**保持全屏，不来回推近拉远**；只有需要看清小元素时（例如视频一里的流程菜单）才推近一次，约 1.45 倍，过渡 1.2 秒，缓动 `cubic-bezier(0.45, 0, 0.25, 1)`，讲完拉回全屏 |
| 聚光 | 需要聚焦某一块时，其余区域盖一层 62% 米白 + 3 px 模糊，0.4 秒淡入淡出 |
| 转场 | 段与段之间用硬切或 0.5 秒淡入淡出；不用花哨转场 |
| 停留 | 关键信息落定后至少停 1 秒；品牌字标停 ≥1 秒 |

**不要用**：弹跳、旋转、3D 翻转、故障风、粒子特效、手持抖动、群发光效、一页里同时动好几样东西。

## 5. 声音

- **背景音乐**：Databend「Tech Content Electronic Background」（Electronic / Downtempo，科技感、节奏平稳；Pixabay Content License，免费商用、不强制署名）。全片只用这一首，不换曲。
  - 作者把同一首曲子出了多个版本（完整版、Instrumental、Loop Edit、Drumless Ambient Loop、60s / 30s Edit、单小节 Loop 等），都在作者主页：https://pixabay.com/users/databend-53307304/
  - 视频一用的是拼好的 7:59 长铺底 `Video/bgm-tech-content-bed.mp3`：**Loop Edit**（76.8 秒，能量全程不变、首尾可无缝循环）循环 5 遍，第 6 遍在 51 秒处 2 秒交叉淡化到 **Instrumental** 版，用它的原版结尾收尾。整首没有安静的间奏，能量一直不变，旁白怎么改都不会撞上段落变化。
  - **视频二直接用同一个文件**，两支片子听起来一致。片子比 8 分钟短时，把音乐的**结尾对齐片尾**，从中间截掉开头多出来的部分（不要从结尾截，否则没有自然收尾），开头加 1 秒淡入。需要更长时，在 Loop Edit 的首尾接缝处再加一遍循环。
  - 需要安静一点的段落（例如纯讲解的架构图），可以把同一位置换成 **Drumless Ambient Loop**（同曲同速、去掉鼓），和主铺底交叉淡化 2 秒。
- **音量**：没有旁白时音乐约 -12 dB；有旁白时压到约 -20 dB；旁白统一到 -6 dB 左右。
- **音效**（少量）：段落切换用轻柔的 whoosh，标题落定用一声轻的 hit，片尾用 riser → impact → sparkle 收束。不要用游戏或卡通音效。
- **配音**：真人录音（课程要求禁用 AI 配音），语速 130–150 词/分钟。

## 6. 片头与片尾

- **片头**：深色（`ink`）背景 + 大号衬线标题，或者米白底 + kicker + 大标题 + 分隔线。
- **片尾**：`ink` 背景，居中排列：铜金色斜体标语 → 细线 → 品牌字标 → 按钮样式的行动号召 → 底部一行小字 `NUS-ISS · INTELLIGENT REASONING SYSTEMS · PRACTICE MODULE`。
- 视频一的标语是 *From resume to offer — every step explained.*，视频二可以沿用，或者换成技术向的一句，但保持同样的版式。

## 7. 给视频二（纯技术讲解）的画面建议

| 讲解内容 | 推荐画面 |
|---|---|
| 系统架构 | 米白底；模块用 1.5 px 边框卡片表示，连线用 `ink` 细线，当前讲到的模块换成 `accent` 边框 + `soft` 底（一次只高亮一个） |
| 技术方向对应（决策自动化 / 知识发现 / 认知技术等） | 沿用视频一的「四大支柱卡片」样式：铜橙编号 + 线性图标 + 衬线卡片标题 + 灰色说明 |
| 算法流程（匹配打分、规则筛选、RAG 检索） | 左边步骤列表逐条出现，右边放代码片段或公式卡片；代码用等宽字体（例如 JetBrains Mono），米白底、`ink` 文字 |
| 评测结果 | 大数字页（同视频一的 "385"）：左边要点，右边一个大号数字 + 一行说明 |
| 关键结论 | `ink` 深色页，2–3 行大号衬线字，最后一行用 `#E9C79A` 强调 |

## 8. 制作工具

视频一用 Remotion 做，但工程文件已经清理掉了，只保留成片和文档。视频二用剪映、PPT 或别的工具都可以，按上面第 1–6 节的颜色、字体、版式和动效数值做，就能和视频一保持一致。可以直接复用的素材是 `Video/bgm-tech-content-bed.mp3`（背景音乐）和 `Video/style-frames/`（代表画面）。

## 9. 代表画面

`Video/style-frames/` 里放了几张视频一的代表帧（标题页、挑战卡、四支柱、演示画面 + 结果标签、可信 AI、定价、片尾），做视频二时可以对照。
