# 视频 1 · 配音脚本（最终版）

> 成片：`IT-CareerPilot-Video1.mp4`（带背景音乐）/ `IT-CareerPilot-Video1-nobgm.mp4`（只有音效），总时长 **6:55**，共 **54 句、789 词**。
> 时间码和成片逐帧对应。同一份内容另有 `video1-voiceover.srt`：**每条字幕是一个完整句子**，条与条首尾相接，下表「字幕」列是这一行对应的字幕编号。**真人录音，不用 AI 配音。**

## 录音前看一眼

**标记**
- **加粗** = 重音，这个词稍微加重、放慢。
- ‖ = 换气 / 停半拍（约 0.3 秒）。
- 「—」= 语气上的转折，不用停，声音往下压一点再接上。

**语速**：整体约 140 词/分（比平时说话稍慢一点）。表里「念完约」是按这个语速估的时长，「可用」是到下一行开口前的时间；两者接近，说明这一行要**连着念、不拖**，念完马上接下一行。

**发音**
| 词 | 读法 |
|---|---|
| CareerPilot | CAREER-pilot，一个词连读，重音在 career |
| IT | 字母 I-T |
| Vue | 同 "view" |
| React | ree-ACT |
| LLM / AI | 逐个字母读 |
| three hundred and eighty-five | 385，不要读成 "three-eight-five" |
| nine-ninety | 即 S$9.90，读 "nine-ninety" |
| practise / practice | 英式拼法，读音一样 |

**录法建议**
1. 剪映里导入 `IT-CareerPilot-Video1-nobgm.mp4`（只有音效，录音时更好对齐）。
2. 「文本 → 本地字幕」导入 `video1-voiceover.srt`，每条字幕的起点就是开口点。
3. **一段一段录**（下面每个小标题是一段），录完把每句拖到对应字幕条的起点。整段一口气录也行，录完按字幕条切开。
4. 配完音、剪好节奏后，再导入背景音乐 `bgm-tech-content-bed.mp3`（7:59，比片子长）放到单独音轨：**把音乐的结尾对齐片尾**，删掉开头多出来的部分，开头加 1 秒淡入，曲子就会在片尾自然收尾。之后改了片长，也照这样重新对齐。
5. 旁白音量统一到约 -6 dB；音乐在有旁白的地方压到约 -20 dB（剪映「音频 → 音量」或「智能闪避」）。
6. 要正式字幕就用「识别字幕」从你的录音生成，删掉导入的提词字幕。

不打算改片长的话，也可以直接用已经混好音乐的 `IT-CareerPilot-Video1.mp4`（音乐已经按上面的方法对齐好）。

## 背景信息（不用念）

- **业务挑战**：卡片上的引语来自公开的 Reddit 讨论（小样本定性调研），所以旁白只说 "We listened to…"，不说"大多数学生""X% 的学生"。
- **岗位推荐**：画面里的最强匹配是 *Software Engineer, Agent (New Grad 2027) · Sierra*（Highly Recommended）；对比的是 *Backend Engineering Intern · AppLovin*（Recommended）。
- **简历改写**：系统留了 `[business outcome / adoption status]` 和 `[task success rate]` 两个占位并提问；学生没有作答直接提交，系统改写时没有加入这些事实。
- **定价**：Starter 免费；Student Pro S$9.90/月或 S$24.90/求职季；Campus Partner 按学生人数年度授权。这是设想的商业方案，不是已实现的功能。
